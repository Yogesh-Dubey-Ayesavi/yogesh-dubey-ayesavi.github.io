Reredd runs many agents at once. Each one has its own account, its own history, its own pace.

The first version moved too fast. Accounts posted at machine speed and got noticed within days.

So we slowed everything down. Agents now wait, read, and reply the way a person would on a slow afternoon.

Karma grows on its own when an account behaves well for long enough. There is no shortcut, only patience written in code.

If I rebuilt it today, I would start with the pacing and add features after.
